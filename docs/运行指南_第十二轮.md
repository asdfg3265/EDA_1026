本轮逐例排查开发集和留出集剩下的失分，修的都是能从图面规律推断出来的通用问题，没有针对公开题或单个案例写规则。公开 13 题的输出和 v14 逐字节相同：平台规则下 99.38，按 10-22 书面规则为 99.79。用 submission_v15.zip 按平台入口实跑了一遍，13 题输出与本地完全一致，单进程共 60 s。

### 主要改动
- **文字颜色**：嘉立创导出图里，位号和网络/电源名是藏青色，型号和取值是亮蓝色。抽查结果：位号全部为藏青，取值和型号全部为亮蓝。本版按颜色区分这两类文字：
  - 亮蓝文字不当位号，藏青文字不当取值；
  - 离开导线的藏青单词（RESET、BOOT、电机A接口）用来给没有位号的器件补名；
  - 位号压在取值上、两行笔画粘连时，按颜色分界切开再识别。
- **电源与端口**：
  - 按形状认出的电源符号可以取电压形式的名字（3V3）。此前这类名字被当成取值跳过，转而取了更远的网络标签，修好后单例 +10 分。
  - 一列紧贴的网络端口改为整列一次性分配。此前标签与端口错开半格时，整列会错位一格。
  - 只出现一次的错读电源名，改成本图多次出现的那个（YDD_3V3 → VDD_3V3，ZVCC25 → VCC25）。
- **器件拆分与合并**：
  - 边贴边叠放的电阻按单元格拆开；
  - LED 的实心光箭头不再被当成地符号，和二极管分开画的箭头并入二极管；
  - 隐藏位号只推给真正独立的芯片本体。
- **类型与引脚名**：
  - 三极管必须有一个单位长的斜线，体二极管片段和 SO-8 封装框不再误判为三极管；
  - 标注规则没有列出的前缀（RST1、CGQ1、DIP1、XL1、FH1）按标注规则判型；
  - 未印引脚名的常见光耦取 AN/CAT/EM/COL；
  - IC 长引脚名在第一个词后丢掉的逗号会补回。
- **位号纠错**：
  - R5. → R5，C-35 → C35，LD01 → LDO1；
  - USBC1 被读成 USBCT、U6 被读成 UE 的情况，按识别器的数字得分纠回；
  - KiCad 引脚号（A6）不再抢走连接器的位号。
- **型号**：常见三极管、二极管系列的型号（AO3401A、1N5819WS、IRL3713PBF）压在导线上也会取作 Name。
