# 运行指南 · 第十三轮（2026-10-26）

## 这一版（v19 代码 / submission_v16）
在 v15 基础上做了三处小改动，都只影响少数图，其他图的输出和 v15 完全一样：
- **绿色地符号**：有的图纸把接地符号画成导线的绿色。此前这些符号被当成导线，整张图的地全部丢失（一张图 30 个）。现在把“几条平行短横、逐条变短、居中对齐”的绿色符号先改画成符号色，再进入解析。在开发集、留出集和合成多风格集共 299 张图上扫描，只在这两张图上出现，没有误检。
- **十六进制器件 ID**：有的器件名是 32 位十六进制 ID（嘉立创器件 uuid）。这类名字先只按 0–9、a–f 重新识别；同一张图上其他副本读对时，读错的副本改成它。
- **标成 X 的 LED**：位号是 X 开头、但画的是带光箭头的二极管时，按 LED 输出，不再当晶振。
