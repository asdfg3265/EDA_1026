# 运行指南 · 第十一轮（2026-10-24）

## 这一版（v17 代码 / submission_v14）
10-23 答疑说最终评测“可能出现图框和功能框”。本轮检查了官方训练图：200 张中有 107 张带图框和标题栏（嘉立创 87 张，Altium、KiCad、Datasheet 也有）。功能框也很常见，有虚线框和实线框，框里写着“电源电路”这类标题。公开 13 题里两类都没有，所以此前的分数反映不出这个问题。

v13 在带图框的官方图上几乎每张都会把整页图框认成一个元件（“A4”“V10”“P1”这类 box，或把版本号“V1.0”认成电源），99 张嘉立创训练图里一共有 91 个这样的整页大框。虚线功能框会和附近的电源符号连成一个大元件；实线功能框的边会抢走旁边接插件的位号。

### 主要改动
- **图框与标题栏**（新文件 `pcbparse/frame.py`）：先从四边寻找贯穿整页的边框线，把边框线、内外框之间的分区编号和刻度、右下角的标题栏擦掉。标题栏的判定很保守：整块和左右两侧都必须是行高很小的表格，并且有竖向分隔线；角落里画了电路的功能框不满足这些条件，不会被擦。只擦完全落在这些区域里的墨迹，和电路相连的笔画保留。
- **只在图纸内容范围内解析**：去掉图框后，按图纸内容的包围盒裁剪，坐标再换算回原图。整页图比电路大得多：此前图像超过 9 MP 就不再放大小字，这类图因此失分（一例从 73.4 提高到 84.9）；裁剪后还更快、更省内存。
- **虚线与点划线**（功能框、分隔线）：识别成串、等距、两侧留白、端头整齐的短直线并擦掉；两个功能框共用一条边时画出的双虚线也能识别。电容极板、地符号横杠、竖排标签中的字母、线圈弧线都不会被误认。
- **实线功能框的边**：没有引脚的长直笔画直接丢弃，不再抢走旁边元件的位号。
- **标题大字**：字高达到页面常规字高 1.8 倍的文字不当作位号和型号（仍可作为网络标签，有的图纸端口标签用大一号字）。
- **内存**：特别长的“文字行”逐个识别，并限制宽度。此前一张 4200×2800 的整页图会在一次批量识别中耗尽 8 GB 内存，v13 处理这张图时进程会被杀掉。
