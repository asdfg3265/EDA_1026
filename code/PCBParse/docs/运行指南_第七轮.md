### 主要改动（详见 `claude/方案进展与结果.md`）
- 粗分区边框不再把线宽估错（这类图从 40–70 分升到约 90 分）；
- 竖排引脚名的下划线、多词引脚名、粘连的竖排电源名（3V3）、竖排文字的阅读方向；
- 连接器引脚号的上下判断参考数字引脚名；引脚号字形贴线、导线盖住引脚末端、器件直接接 GND 时的连接点；
- 晶体管的分段笔画（体二极管、漏极短线）先合并再分配位号；叠放的两脚器件按引脚行切开；菱形短接符号、分区线不再当成器件；
- 位号、型号、类型、电源名的一批先验修正；器件库补入训练案例中的芯片引脚表（Q&A：测试用芯片都在 200 例或 cpntLibrary 里）；
- 新增的细化步骤大多列入“安全模式”：单例出现异常时会关掉它们重跑一次。
