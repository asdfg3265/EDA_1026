# 运行指南 · 第九轮（2026-10-22）

## 这一版（v15 代码 / submission_v12）：支持 Altium、KiCad 等其他工具的图
答疑 A76 明确“评测 case 不限制风格”。官方训练集的彩色图里约三成来自 Altium Designer、KiCad 等工具，v11 在这些图上几乎全是 0 分（37 张非嘉立创训练图平均 2.5 分）。

v12 在解析前加了一步**风格归一化**（`pcbparse/style.py`）：
- 先判断是不是嘉立创配色（绿色导线 + 蓝/藏青文字 + 没有青色文字）。**嘉立创图原样不动**——421 张嘉立创图（训练 jlc 99、公开 13、缩放 26、开发 99、留出 184）全部判对；公开 13 题输出与 v11 逐题相同（平台规则 99.3845）。
- 其他工具的图：按颜色、形状和位置给每个像素定角色（导线、连接点、符号、文字；框内引脚名和引脚旁的引脚号为黑字，其余为蓝字），把网格和本体填充色当作纸，再用嘉立创配色重画，交给原来的流程。
- 归一化出任何异常都会退回原图。

| 合成验证（开发集图换成别的软件配色，标注不变，各 8 例） | 嘉立创原版 | v11 | **v12** |
|---|---|---|---|
| Altium 配色 | 89.5 | 5.0 | **78.6** |
| KiCad 配色 | 89.5 | 4.6 | **83.7** |

真实训练图（37 张非嘉立创）平均 2.5 → 5.8。注意这些训练图的标注 bbox 是按类型固定尺寸画的（电阻 8×20、电容 16×20…），与正式评测“完整明确的框”不同，所以绝对分数没有参考价值，只看方向。

其他改动：晶振、运放按 10-22 评分说明的类型附录输出为 `crystal`、`amp`（公开 13 题里没有这两类，平台分数不变）。
