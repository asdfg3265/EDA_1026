### 主要改动（详见 `claude/方案进展与结果.md`）
- 网络标签：旗形堆叠里导线直接顶在旗尖上（零长度引脚）、夹着一个电源符号、外缘有导线经过时都能拆开；纯矩形端口（名字写在框内）重新识别；旗形直接画在两脚器件端点上时切出；
- 地符号：贴在旗形堆叠上的地符号能切出来（先切地，再拆堆叠），切出的地符号保留导线端点并读取自己的名字；侧放地符号的名字与符号顶端平齐时也能读到；
- 型号：一次性最优分配（不会因为邻居离得近而丢掉自己唯一的型号）；元件库型号加分要求引脚数相符；纯数字不作二极管/LED 的型号；
- 位号：带电压尾缀的文字（DCDC12V）不当位号；紧贴在干净位号下一行的型号样文字（D1 下面的 S10M）让位；
- 运放：按芯片方式读引脚号与 +/− 引脚名；
- 取值：大写单位（10UF、100NF）不再被改成数字；电容值缺了 μ 时补回；
- 两脚器件：长于 1.75u 的引线算符号图形（bbox 在引脚端点内 1u）；被文字截断的引线接回；
- 回归修复：变压器内画小方框不再判成芯片；LED 箭头按方向归属（不并给箭头所指的相邻 LED）；数码管内部的段不单独成件。
- 新增步骤都列入“安全模式”：单例出现异常时会关掉它们重跑一次。
