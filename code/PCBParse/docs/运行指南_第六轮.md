# 运行指南 · 第六轮（2026-10-21 晚）

## 平台为什么只有 97.99
平台已改用新协议 `2026-10-18-independent-thresholds-only`：
- IC 引脚阈值 **5 px**（元件 bbox 仍是 20 px，导线 5 px）；
- 网络标签类型严格比较，标准答案用的是 **net_input / net_output / net_bidirection**（由端口箭头方向决定）。

我们的预测和本地完全一致，差别全在规则。本地评分器已改成这套协议，v8 的预测在本地复现 97.987，13 题逐题与平台一致。

## 这一版（v12 代码 / submission_v9）
| 数据 | v8（平台现规则） | v9 |
|---|---|---|
| 公开 13 题（标签类型按箭头形状推断，见 data/open_GT_v2） | 97.99（平台实测） | **≈99.17**（本地） |
| 开发集 99 例（新标注 v5：同位号多部件 + 端口类型） | 80.54 | **81.81** |
| 留出集 184 例 | 评测中 | 评测中 |

改动：
- 网络标签按箭头方向输出类型；
- 贴在其他元件上的 GND 符号、叠画的 GND 和 LED 能拆开；
- 未连接引脚的“×”标记、导线小绿点挡住引脚末端时，引脚端点移到标记中心（适配 5 px 阈值）；
- 电感直接接在连接点上时补引脚；
- 元件库按大小写严格比较（不再把 VIN 改成 Vin）。
